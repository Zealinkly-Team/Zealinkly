# UI修复验证指南

## 快速验证步骤

### 🎯 验证1: 欢迎卡文本闪烁修复

**步骤:**
1. 完全关闭应用
2. 清除应用缓存（可选）
3. 重新启动应用
4. 观察首页顶部的欢迎卡

**✅ 成功标准:**
- 初始只显示"欢迎"（不带姓名）
- 加载完成后平滑过渡到"欢迎，{您的姓名}"
- **不会出现**"欢迎，老人"的字样

**❌ 如果仍然闪烁:**
- 检查网络连接
- 查看Logcat日志是否有错误
- 确认 `getUserInfo()` API调用成功

---

### 🎯 验证2: PENDING按钮功能修复

**准备工作:**
需要一个状态为PENDING的任务。有两种方式获取：

**方式A - 创建新任务:**
1. 在"任务"界面点击"发布新任务"
2. 填写任务信息并发布
3. 使用志愿者端接单
4. 志愿者完成并提交证据
5. 任务状态变为PENDING（等待老人确认）

**方式B - 使用现有PENDING任务:**
如果已有PENDING状态的任务，直接进入验证步骤

**验证步骤:**
1. 打开"任务"界面（底部导航栏）
2. 找到状态为"PENDING"的任务卡片
3. 检查任务卡片是否显示"确认完成"按钮

**✅ 成功标准:**
- PENDING任务卡片底部显示蓝色"确认完成"按钮
- 按钮包含对勾图标和文字
- 点击按钮后：
  - 按钮变为不可点击状态（加载中）
  - 任务列表自动刷新
  - 任务状态更新（按钮消失或状态改变）
  - 积分增加（如果后端实现了）

**❌ 如果按钮点击无响应:**
- 检查Logcat日志查看错误信息
- 确认后端API `PUT /api/elder/tasks/{taskId}/confirm` 可访问
- 检查网络连接
- 确认Token未过期
