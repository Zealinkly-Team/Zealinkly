# 通知和紧急联系人功能 - 快速使用指南

## 📱 用户使用流程

### 通知功能

#### 1. 如何查看通知
```
个人资料界面 → 快速操作 → 点击"通知"
     ↓
进入通知列表 → 查看所有通知
     ↓
未读通知 = 蓝色小圆点标记
已读通知 = 普通灰色显示
```

#### 2. 标记通知为已读
```
方式1：点击未读通知 → 自动标记为已读

方式2：点击"全部已读"按钮 → 确认 → 所有通知标记为已读
```

#### 3. 通知类型示例
- 📋 **任务通知** - 任务状态变化（已接单、已完成等）
- ⭐ **积分通知** - 积分增加、奖励到账
- ⚠️ **系统通知** - 系统维护、公告等
- 🚨 **紧急通知** - 紧急报警、重要提醒

### 紧急联系人功能

#### 1. 如何查看紧急联系人
```
个人资料界面 → 快速操作 → 点击"紧急联系人"
     ↓
进入紧急联系人列表 → 查看所有联系人
     ↓
显示：姓名、关系、电话号码、优先级
```

#### 2. 添加新联系人
```
进入紧急联系人界面 → 点击右下角[+]按钮 → 填写表单
     ↓
填写项：
  • 姓名：请输入真实姓名
  • 关系：子女、配偶、朋友、其他等
  • 电话号码：请输入11位手机号
  • 优先级：1-5（数字越小优先级越高）
     ↓
点击"保存"按钮 → 联系人添加成功
```

#### 3. 编辑联系人信息
```
联系人列表 → 找到要编辑的联系人 → 点击[编]按钮
     ↓
修改相关信息 → 点击"保存"按钮
     ↓
联系人信息更新成功
```

#### 4. 删除联系人
```
联系人列表 → 找到要删除的联系人 → 点击[删]按钮
     ↓
确认删除提示 → 点击"删除"按钮
     ↓
联系人删除成功
```

#### 5. 优先级说明
```
优先级排序：
1 号联系人 → 最高优先级（紧急报警时首先通知）
2 号联系人 → 第二优先级
3 号联系人 → 中等优先级
...
5 号联系人 → 最低优先级（最多添加5个）

建议设置：
优先级1：子女/紧急度最高的人
优先级2：配偶/亲近的人
优先级3-5：其他家人/朋友
```

## 🐛 故障排除

### 问题1：通知界面显示空白
**症状：** 进入通知界面后什么都没显示

**可能原因：**
- 后端API未返回数据
- 网络连接问题
- Token过期

**解决方案：**
1. 检查网络连接
2. 查看Logcat中是否有错误信息
3. 重新登录获取新Token
4. 检查后端服务是否正常运行

### 问题2：添加联系人失败
**症状：** 点击保存后没有反应或提示错误

**可能原因：**
- 表单验证失败
- 后端API返回错误
- 网络连接断开

**解决方案：**
1. 确保填写所有必填项
2. 电话号码格式是否正确
3. 查看错误消息提示
4. 检查网络连接

### 问题3：联系人列表显示错乱
**症状：** 列表顺序混乱或显示重复

**可能原因：**
- 缓存数据未同步
- 优先级值设置重复

**解决方案：**
1. 关闭应用重新启动
2. 重新编辑联系人确保优先级唯一
3. 清除应用缓存

### 问题4：返回按钮不工作
**症状：** 点击返回无反应或页面卡顿

**可能原因：**
- 导航栈错误
- 页面加载中被中断

**解决方案：**
1. 等待页面加载完成
2. 使用物理返回键
3. 重启应用

## 📊 性能优化建议

### 对于大量通知
- 实现**分页加载**：每次加载20条，滚动到底部加载更多
- 实现**搜索功能**：按标题或日期搜索
- 实现**通知清理**：自动删除30天前的通知

### 对于用户体验
- 实现**通知声音/振动**：到达新通知时提醒
- 实现**通知分类**：按类型分页显示
- 实现**通知统计**：显示各类型通知数量

### 对于网络状况
- 实现**离线缓存**：断网时显示本地缓存
- 实现**增量更新**：只同步变化的数据
- 实现**自动重试**：网络恢复时自动同步

## 📞 支持信息

### 常见问题
1. **为什么通知有延迟？**
   - 后端推送延迟或网络问题
   - 建议手动刷新查看最新通知

2. **联系人信息会不会泄露？**
   - 联系人仅存储在用户账户下
   - 紧急报警时才会发送给管理员

3. **最多可以添加多少个联系人？**
   - 目前限制为5个
   - 可根据需求调整

4. **删除的联系人可以恢复吗？**
   - 目前不支持恢复
   - 建议删除前确认
