# 智链邻里 - 管理员前端项目

## 项目介绍

这是智链邻里系统的管理员前端项目，基于 Vue 3 + Element Plus 开发，用于管理老人、志愿者、任务等各项内容。

## 项目结构

```
admin-frontend/
├── src/
│   ├── views/
│   │   ├── auth/         # 认证相关页面（登录、注册）
│   │   ├── manager/       # 管理后台页面
│   │   ├── Home.vue       # 首页
│   │   └── Manager.vue    # 管理后台主布局
│   ├── router/
│   │   └── index.js       # 路由配置
│   ├── components/        # 组件
│   ├── assets/            # 静态资源
│   ├── App.vue            # 根组件
│   └── main.js            # 入口文件
├── package.json           # 项目配置
├── vite.config.js         # Vite 配置
└── index.html             # HTML 模板
```

## 环境要求

- Node.js 16+
- npm 7+

## 安装和运行

1. **安装依赖**

```bash
cd admin-frontend
npm install
```

2. **运行开发服务器**

```bash
npm run dev
```

3. **构建生产版本**

```bash
npm run build
```

4. **预览生产构建**

```bash
npm run preview
```

## API 接口

前端项目默认连接的后端 API 地址为 `http://localhost:8080`，与后端项目的开发环境地址保持一致。

## 注意事项

1. **跨域问题**：如果后端 API 地址与前端地址不同，需要在后端配置 CORS 允许跨域请求。

2. **认证**：所有管理接口都需要在请求头中携带 JWT Token，格式为 `Authorization: Bearer <token>`。

3. **权限**：系统会验证用户类型是否为 `ADMIN`，非管理员用户无法访问管理接口。

4. **数据格式**：所有时间字段使用 ISO 8601 格式，时区为北京时间（Asia/Shanghai）。

## 开发建议

1. **代码规范**：遵循 Vue 3 的代码规范，使用 Composition API 进行开发。

2. **组件化**：将重复的 UI 元素抽象为组件，提高代码复用性。

3. **状态管理**：对于复杂的状态管理，可以考虑使用 Pinia。

4. **API 封装**：建议封装 Axios 请求，统一处理错误和认证。

5. **响应式设计**：确保页面在不同设备上都能正常显示。
